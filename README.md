# Arsip Digital Guru (APK Android Offline)

Aplikasi penyimpanan arsip digital guru berbasis Android offline dengan fitur:
- **Upload Berkas** (PDF, Word, Excel, Gambar)
- **Scan Kamera** langsung dengan peningkatan kontras dokumen otomatis
- **Filter & Manajemen Kategori** (Tambah/Hapus kategori secara mandiri)
- **Share Berkas** ke WhatsApp, Email, atau aplikasi pembaca dokumen

## Cara Build APK di GitHub
1. Upload seluruh isi folder ini ke repository GitHub Anda (branch `main`).
2. Buka menu **Actions** di repository GitHub.
3. Tunggu proses **Build Android APK** selesai (ikon centang hijau).
4. Unduh file APK di bagian **Artifacts -> Arsip-Digital-Guru-APK**.
